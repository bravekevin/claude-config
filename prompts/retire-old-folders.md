# 지시문 — iCloud 안 옛 프로젝트 폴더 정리

사용자는 옛 폴더가 있는 컴퓨터의 세션에 이렇게 붙여 넣는다.
> ~/.claude-config/prompts/retire-old-folders.md 대로 <옛 폴더 경로> 를 정리해줘.

전제: `prompts/migrate-project.md` 를 끝내서 `~/Dev/<폴더>` 가 있고, 옛 폴더의 작업이 GitHub에 다 올라가 있다.

---

## Claude가 할 일

### 0. 지켜야 할 것
- **지우는 일은 되돌리기 어렵다.** 아래 확인을 모두 통과하고, 지울 목록을 보여 준 뒤 사용자 승인을 받는다.
- 바로 지우지 않고 휴지통으로 옮긴다(`mv <폴더> ~/.Trash/`). 사용자가 휴지통을 비운다.
- 이 세션 자신이 그 폴더 안에서 돌고 있으면 정리하지 않는다. 사용자에게 `~/Dev/<폴더>` 에서 새 세션을 열어 다시 시키라고 안내한다.

### 1. 안전 확인 (하나라도 실패하면 멈추고 보고)
1. `git-safety audit <옛 폴더>` — 원격에 없는 커밋 0. 커밋 안 된 변경은 "원격 스냅샷과 같음(백업됨)"이어야 한다. 아니면 `git-safety backup --yes <옛 폴더>` 를 먼저 한다.
2. `~/Dev/<폴더>` 가 있고 `git-safety audit` 이 "안전".
3. 그 폴더를 쓰는 세션이 없는지: `git worktree list` 의 각 경로, `lsof +D <폴더> 2>/dev/null | head`, Claude 데스크톱 앱의 다른 세션(사용자에게 확인). 쓰는 중이면 멈춘다.
4. env 파일이 `~/Dev/<폴더>` 쪽에도 있는지(파일 존재만, 내용 안 봄).

### 2. 정리 목록 보여 주기
- 옛 메인 폴더, 같은 저장소의 다른 worktree 폴더(`git worktree list`), `/tmp` worktree.
- 각 항목: 경로, 크기(`du -sh`), 브랜치, 백업 위치(원격 브랜치 이름).

### 3. 승인 뒤
- worktree 는 `git -C <옛 메인> worktree remove <경로>`(변경 있으면 실패 → 멈춤). 실패 없이 끝나면 옛 메인 폴더를 `~/.Trash/` 로.
- Claude 메모리는 `~/.claude-private` 에 있으므로 지워지지 않는다. `~/.claude/projects/<옛 경로키>/memory.pre-link-*` 폴더는 그대로 둔다(사용자가 원하면 나중에).
